# Unreal Canvas 简体中文验收记录

以下记录为各功能版本在开发时的实测。公开源码的检查与重新编译另见本版本的 GitHub Release。

历史记录中的路径对应当时的检出。当前版本从 `Tools/Frontend/` 运行前端验证脚本。本机历史截图在 `Tools/Artifacts/Verification/Screenshots/`，原始记录在 `Tools/Artifacts/Verification/Runs/`。

## 0.2.13 · 2026-11-24

对照 UE 5.9 Preview 2 和 Canvas 0.24.0 的实际加载资源排查漏译。前端从 [translate.ts](../Frontend/src/translate.ts) 按控件和内容定位系统文案。UE 原生界面从 [NativeShell 词库](../NativeShell/) 生成的资源读取简体中文。

| 界面 | 原因和改动 |
| --- | --- |
| 未保存确认、生成工具架 | 宿主在运行时按可用操作生成整句提示，部分按钮也改用了新拼写和大小写。匹配实际弹窗、按钮和输出菜单，保留用户的卡组名称。 |
| 画布和节点图右键菜单 | 同一个命令在不同入口可能有不同标签。三级菜单挂在独立浮层，旧选择器找不到按钮。按宿主动作标识和当前菜单匹配新增词条。 |
| 旧画布的渲染通道 | 旧节点缺少通道名称清单。通过内置输出引脚的类型、方向、名称和 ID 识别标准通道。 |
| 原生节点图、查看器和空间批注 | 上游已有本地化文本键，但该版 UE 的简体中文资源仍返回英文。补译 346 条，其中节点图 223 条、查看器 64 条、空间批注及相关设置 59 条。 |
| UE 插件列表里的介绍 | `SPluginTile.cpp` 直接用 `FText::FromString` 显示官方 `.uplugin` 的名称和说明，这两个字段没有可供汉化插件匹配的文本键。空间批注的部分形状名和卡面编辑器的方向参数也由宿主直接传入。 |

- TypeScript 检查、前端构建和 40 项自动化测试通过。编辑器和独立 App 的本机服务均提供与随包产物逐字节一致的 0.2.13 脚本。
- 用本机服务和隔离 Chromium 实际点验关闭节点图、工具架输出位置、卡片右键菜单、节点图输入切换及旧视口渲染节点。检查了同名卡片、卡组和自定义通道的原名保护。关闭确认中的取消保留编辑，放弃恢复到保存前的测试状态。
- 逐项核对 625 个原生文本的源文哈希、占位符和编译词库。独立 UE 进程在简体中文下读到全部 625 条译文，在英文下读到 346 条新增键对应的官方原文。原生 Slate 面板的布局与当前编辑器窗口的重载待点验。
